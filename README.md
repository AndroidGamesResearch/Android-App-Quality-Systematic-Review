# Android App Quality SLR

Research artifacts for the paper:

**What Gets Measured Gets Studied: A Cross-Attribute Systematic Review of Android Application Quality Revealing Measurability Bias and Its Implications**

This repository contains the data and analysis artifacts from a systematic literature review of Android application quality. The study analyzes 81 primary studies using the ISO/IEC 25010 quality model and examines how measurability influences research attention across software quality attributes.

## Contents

- SLR data and study selection
- Quality assessment and attribute mapping
- Cohen's Kappa analysis
- Analysis code and supporting results
